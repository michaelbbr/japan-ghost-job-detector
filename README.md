# 👻 Japan Ghost Job & Black Kyujin Radar (日本版 幽靈・釣魚職缺偵測器) v2.0

> **在投出履歷與面試前，看清日本求職網上的「幽靈職缺（カラ求人）」與「釣魚誘餌（おとり求人）」，提供多維度客觀證據與避雷建議，而非憑空斷言。**

本專案專為前往日本求職、在日轉職以及尋找日本遠端工作的求職者設計，深度參考兩大開源專案的核心理念：

- **[fansia/104-ghost-job-detector](https://github.com/fansia/104-ghost-job-detector)**：反對武斷黑箱扣分、深度解析平台招募生態、客觀區分「常態人才儲備庫（Talent Pool）」與「惡意假職缺」。

## 🗾 「看日本都啥求職」—— 日本求職生態與主流平台全圖譜

如果您正準備在日本求職或了解日本職場，日本的招聘市場有極具特色的分類與文化體制：

### 1. 主流求職平台全覽

### 2. 日本特有求職陷阱深度拆解

1. **カラ求人 (Kara Kyujin / 空頭假職缺)**：
   - 企業完全沒有僱用意願。在 Hello Work 尤為嚴重（為維持請領政府「雇用調整助成金」資格）；在商業求職網則是為了向投資人與客戶展示「公司正處於爆炸性擴張」的公關效果。
2. **おとり求人 (Otori Kyujin / 誘餌釣魚職缺)**：
   - 人材仲介公司（エージェント）或 SES 派遣公司的慣用手法。刊登「完全遠端・未經驗年薪500萬・自社SaaS開發」的假職缺，求職者應徵後人資回覆「該職缺剛額滿，改推其他客戶端常駐（客先常駐）專案」。
3. **みなし残業（固定残業代）的數字障眼法**：
   - 表面開出「月薪 35 萬日圓」，小字註明「含固定加班費 45 小時（甚至 60 小時）」。扣除後底薪甚至低於東京都法定最低時薪！且加班若超過 45 小時，常被黑心企業以情緒勒索拒發超時津貼。
4. **SES 多重下請け（偽裝自社開發）**：
   - 宣稱「自社產品開發」，入社後立刻被派去金融機構或外包第三層（3次請け・4次請け）當人月工時（客先常駐），技術無法累積。
5. **やりがい搾取・アットホーム欺瞞（黑心企業精神論）**：
   - 職缺描述充斥「アットホームな職場（家庭般溫馨）」、「夢・感動・成長」、「若手が活躍」等情緒詞彙，對具體技術棧、職責、加薪考核制度隻字不提。
6. **闇バイト (黑工・洗錢詐欺)**：
   - 以「高額日給3萬」、「荷物転送業務（包裹轉寄代收）」、「口座開設（人頭帳戶）」、「Telegram/Signal聯繫」等話術，誘騙外國人或年輕人涉入違法洗錢犯罪。

## ✨ 本系統核心功能 (Features)

- 🎯 **多維度幽靈風險評分 (Ghost Score 0–100)**：結合採用系統認證、刊登滯留天數、殘業條款、黑心語法與批次重複度綜合推估。
- 🏢 **日本主流 ATS 採用系統即時辨識**：自動識別 `HERP Hire`、`Talentio`、`SmartHR`、`HRMOS`、`JobSuite`、`Greenhouse`、`Workday`、`Lever` 等正規招募系統。
- ⏱️ **固定殘業（みなし残業）深度剖析**：自動提取固定殘業時數，標註超過法定 36 協定 45 小時上限之過勞死風險。
- 🔄 **批次重複與歷史定時重貼偵測**：檢測清單中被不同派遣仲介洗版，或同公司以不同日期反覆重貼之職缺。
- 📋 **透明證據抽屜 (Evidence Drawer)**：逐條列出已驗證的具體事實，清楚揭示哪些資料被核實、哪些無法驗證。
- ⚠️ **客觀免責說明 (Caveats)**：借鑑 fansia 與 Farhan 理念，標示合理例外（如大型外商人才庫、Wantedly 不標薪法規要求），避免武斷誤判。
- 🛡️ **一鍵直連 OpenWork 企業評價**：每張職缺卡片均附帶 OpenWork 搜尋捷徑，直擊真實員工爆料工時與年薪。
- 📂 **支援日文 CSV 批次匯入與單筆文字貼上診斷**：自動映射「職種 / 企業名 / 勤務地 / 給与 / 掲載日 / 応募URL」。
- 🧪 **內建 10 筆真實情境測試數據**：涵蓋 Mercari 正式直招、Indeed 派遣洗版急募、LinkedIn Promoted 幽靈缺、SES 釣魚、黑心精神論企業與闇バイト等。

## 🚀 快速啟動 (Quick Start)

### 系統需求
- Node.js 20.0+ 或 22.18+

### 1. 安裝相依套件
```bash
npm install
# 或使用 npm ci
```

### 2. 啟動本機開發伺服器
```bash
npm run dev
```

開啟瀏覽器造訪 **http://localhost:3000** 即可開始使用！

### 3. 建置生產環境版本
```bash
npm run build
npm run start
```

## 📋 CSV 匯入格式支援

支援標準 CSV 檔案上傳，系統具備智慧欄位映射，無論使用英文或日文欄位名皆可自動辨識：

| 欄位名稱 (英/日) | 必要性 | 說明 | 範例 |
|---|---|---|---|
| `title` / `職種` / `求人タイトル` | ✅ 必要 | 職缺職稱 | Senior Frontend Engineer |
| `company` / `企業名` / `会社名` | ✅ 必要 | 企業名稱 | 株式会社メルカリ |
| `location` / `勤務地` | 選填 | 工作地點或遠端體制 | 東京都港区 / フルリモート |
| `salary` / `給与` / `年収` | 選填 | 薪資待遇與殘業說明 | 年収 800万〜1200万円 (固定残業代なし) |
| `posted_date` / `掲載日` / `更新日` | 選填 | 刊登或更新日期 | 2026-08-25 |
| `apply_link` / `応募URL` / `求人URL` | 選填 | 應徵或官方 ATS 網址 | https://herp.careers/v1/mercari/... |
| `description` / `詳細` / `業務内容` | 選填 | 職務詳細描述與條件 | 負責 Web 系統開發... |

可於頁面上下載內建之 `sample_japan_jobs.csv` 進行測試。

## 🛡️ 求職者避雷行動指引 (Actionable Checklist)

1. **投遞履歷前**：
   - 於 **OpenWork** 搜尋該公司，確認平均加班時數是否超過 40 小時、評分是否低於 3.0。
   - 於日本國稅廳「**法人番号公表サイト**」確認該公司是否有實體登記總部。
2. **面試過程中**：
   - 確認實際就業場所：是「本社辦公室/自宅遠端」還是「客戶端現場（客先常駐）」？
   - 確認固定加班費制度：是否有超過規定時數後的「超過分全額支給」？
3. **收穫內定時**：
   - 依據日本《勞動基準法》第15條，要求公司出具書面《**労働条件通知書**》。
   - 核對合約上的契約期間是否為「無期雇用（正社員）」，警惕試用期被暗中降為「契約社員」或「業務委託」。
